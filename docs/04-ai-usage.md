# 04 AI 使用与个人贡献

## 我的工作

我给出内容任务规划题的输入和成功标准，强调预算、截止时间、步骤状态必须对应；预算超限后要重新规划，工具失败时保留已成功的结果，重复执行不得重复保存或重复计费。我要求按统一交付规范复查第二题，重点核对真实模型根据成本和错误结果改选动作，以及失败步骤续跑是否成立。

我创建公开 GitHub 仓库并提供真实模型运行条件。我审阅代码后，向 Codex 提出修改意见：修复测试数据库连接清理问题，在输出中单列失败步骤耗时，并补充真实模型保存失败后恢复的证据。我用这些具体问题推动第二轮修改和验证。

## AI 辅助范围与分工

我使用 Codex 编写和修改 CLI、合成素材、费用与耗时规则、SQLite 状态、测试、示例和文档；DeepSeek 在运行时通过工具调用选择动作。Codex 负责实现、执行测试、保存运行记录与提交仓库。MockPolicy 是离线预设策略，只能验证业务流程和约束，不能替代真实模型决策证据。
