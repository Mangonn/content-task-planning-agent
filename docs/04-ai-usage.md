# 04 AI 辅助与贡献记录

## 使用范围

本仓库代码、合成资料、测试、示例生成器和文档由 Codex AI 助手在对话中编写、修改和本地验证。运行时的真实决策模型为 DeepSeek；它只通过 function calling 选择 CLI 中的业务工具，没有生成或修改仓库代码。离线 `MockPolicy` 为显式规则策略。

用户提供了考核题目、验收与高分关注点，并创建公开 GitHub 仓库、提供真实模型调用条件。当前记录没有可核实的用户手工代码修改，因此不将 AI 生成代码表述为候选人独立编写。提交者如后续亲自改动，应在新的提交中补充自己的修改与验证记录。

## 修改与验证记录

1. AI 助手实现四个合成业务工具、预算和耗时核算、SQLite 状态与防重复、CLI 和 DeepSeek 模型适配。
2. AI 助手为保存前增加依赖及可行性复核；为断点续跑保留成功步骤。失败步骤保持 `failed`，保存超时返回 `incomplete`。
3. AI 助手检查真实模型 Trace 后，将并行调用拒绝明确标为 `parallel_calls_rejected`；该控制事件不计业务工具调用数。
4. AI 助手运行 16 项自动测试、13 组离线样例、2 组真实模型样例，逐项核对实际输出，证据见 [`03-evaluation.md`](03-evaluation.md)。

模型密钥仅用于本地运行，没有写入仓库或示例文件；`.env` 已列入 `.gitignore`。使用真实模型的记录仅证明当次模型行为，不以 Mock 结果代替。
